# Agentic Multimodal RAG

Document-answering agent: reads text, tables, and images from PDFs, reasons with tools (retrieval, calculator, web search), cites its sources, and evaluates/traces its own runs. Built with free/open-source tools only (Groq API, ChromaDB, LangGraph, RAGAS, Langfuse).

Work in progress — see project roadmap for build status.
